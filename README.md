## FORM AI 📃🤖
 
   People struggle filling out long forms, you see this in cyber cafes (hint: i worked there) during NYSC registration or JAMB .
   The goal is to let AI do the boring repetitive tedious work , Its for anyone collecting large data from users

   USER FILLS FORM, THE IMAGE OF THOSE FORMS GET UPLOADED TO AN AI MODEL, MODEL READS IT AND FILLS THE RESPECTIVE INPUT FIELDS WITH DATA (FASTER THAN TYPING ⚡).


## 🚀 Core Features

  - **Zero Manual Typing:** Extracts handwriting and structured text from printed or scanned documents instantly.
  - **Smart Field Mapping:** Automatically aligns extracted data with complex registration fields (e.g., bio-data, academic history).
  - **High-Throughput Processing:** Designed specifically to speed up bottlenecks at registration centers and cyber cafés.
  - **Real-Time UI Pre-Filling:** Populates standard HTML/React forms natively for instant user verification before submission.

## 📦 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org) installed (v18 or higher recommended) along with `pnpm` (or your preferred package manager).

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ugochukwu111/form-ai.git
   cd formAI
   ```

2. **Install the dependencies:**
   ```bash
   pnpm install
   ```

3. **Configure your API keys:**
   Create a `.env` file in the root directory:
   ```env
   Coming soon!
   ```

4. **Launch the local development engine:**
   ```bash
   pnpm run dev
   ```
   Open `http://localhost:3000/` in your browser to test the local build.
